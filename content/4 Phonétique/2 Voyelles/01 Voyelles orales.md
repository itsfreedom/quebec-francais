| 소리 | 예시 | 메모 |
|---|---|---|
| [i] | six, lit, ils | 입을 옆으로 벌림 |
| [y] | salut, tu, vue | [i] 입모양 그대로 입술만 동그랗게 (한국어에 없는 소리) |
| [u] | bonjour, goût, nous | "우" |
| [e] | et, parlez, blé | 닫힌 "에" |
| [ø] | deux, heureux, bleu | [e] 입모양에서 입술만 동그랗게 |
| [o] | allo, eau, drôle | 닫힌 "오" |
| [ə] | je, le, que | 약한 "으", 힘 빼고 |
| [ɛ] | sept, fait, projet | 열린 "에" |
| [œ] | neuf, œuf, sœur | [ɛ] 입모양에서 입술만 동그랗게 |
| [ɔ] | votre, dort, anglophone | 열린 "오" |
| [a] | ça, ami, pas | "아" |
| [ɑ] | parler, tâche, passé | 뒤쪽 "아" (요즘은 [a]와 거의 구분 안 함) |

> [!tip] 입 벌림 정도 (Aperture)
> **Fermé** [i y u] → **Mi-fermé** [e ø o] → **Mi-ouvert** [ɛ œ ɔ] → **Ouvert** [a ɑ]
> 앞쪽 모음 [i e ɛ a], 같은 위치에서 입술을 동그랗게 하면 [y ø œ], 뒤쪽 모음 [u o ɔ ɑ]
