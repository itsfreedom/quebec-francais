# Élision (엘리지옹)

← [[00 Phonétique|Phonétique]] · 처음 배운 수업: [[2026-11-18]]

모음이나 h 앞에서 **e나 a가 빠지고 아포스트로피(')**가 붙어요.

| 원래 | 엘리지옹 | 뜻 |
|---|---|---|
| je + ai | **j'ai** | 나는 가지고 있다 |
| le + ami | **l'ami** | 그 친구 → [[01 Articles définis\|Articles définis]] |
| la + eau | **l'eau** | 물 |
| que + il | **qu'il** | 그가 ~라는 것 |
| ne + est | **n'est** (pas) | ~이 아니다 → [[01 Négation\|Négation]] |
