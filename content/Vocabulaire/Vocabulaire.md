# 📚 Vocabulaire (단어 · 표현)

← [[Francisation]]

## 찾는 방법
| 이렇게 찾고 싶으면 | 여기로 |
|---|---|
| 철자를 알 때 (사전처럼) | 🔤 [[Dictionnaire]] — `Mots/A`, `Mots/B` … 첫 글자 폴더 |
| 주제로 모아 보고 싶을 때 | 📂 [[Thèmes]] — 색깔, 숫자, 가족 … (플래시카드 포함) |
| 상황별 문장 | 💬 [[Expressions]] — 인사, 수업 시간, 서류 작성 … (플래시카드 포함) |
| 대화 전체 | 🗣 [[00 Dialogues]] |

> [!info] 정리 규칙
> - **단어 하나 = 노트 하나**. 파일 이름은 단어 그대로예요 (예: `Mots/S/sœur`). 관사 없이 쓰고, 악센트는 무시하고 첫 글자 폴더에 넣어요 (é → E).
> - 같은 단어가 다른 수업에 또 나오면 새로 만들지 않고, 단어 노트 아래 **나온 수업**에 날짜를 더해요.
> - **플래시카드는 주제 노트와 상황 노트에만** 있어요 (`#flashcards/francais`). 단어 노트에는 없어요.
> - 노트 맨 위 속성(YAML)은 언어 학습 앱용 데이터예요 → [[_Schema]]
