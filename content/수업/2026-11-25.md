## 👩‍⚕️ Les professions · 직업 (남성 · 여성 · 복수)

> [!important] 끝 모양을 보면 여성형이 보여요: **-er → -ère** · **-e → 그대로** · **+e** · **-eur → -euse** · **-teur → -trice** · 복수는 **+s**

| Terminaison 끝 모양 | Le masculin 남성 | Le féminin 여성 | Le pluriel 복수 |
|---|---|---|---|
| **-er → -ère** | [[cuisinier\|le cuisinier]] | la cuisinière | les cuisiniers / les cuisinières |
| | [[infirmier\|l'infirmier]] | l'infirmière | les infirmiers / les infirmières |
| | [[boulanger\|le boulanger]] | la boulangère | les boulangers / les boulangères |
| | [[épicier\|l'épicier]] | l'épicière | les épiciers / les épicières |
| **-e → -e** (pas de changement) | [[dentiste\|le dentiste]] | la dentiste | les dentistes |
| | [[photographe\|le photographe]] | la photographe | les photographes |
| | [[fleuriste\|le fleuriste]] | la fleuriste | les fleuristes |
| | [[pianiste\|le pianiste]] | la pianiste | les pianistes |
| | [[artiste\|l'artiste]] | l'artiste | les artistes |
| | [[secrétaire\|le secrétaire]] | la secrétaire | les secrétaires |
| **+e** au féminin | [[avocat\|l'avocat]] | l'avocate | les avocats / les avocates |
| | [[professeur\|le professeur]] | la professeure | les professeurs / les professeures |
| | [[écrivain\|l'écrivain]] | l'écrivaine | les écrivains / les écrivaines |
| **-eur → -euse** | [[coiffeur\|le coiffeur]] | la coiffeuse | les coiffeurs / les coiffeuses |
| | [[danseur\|le danseur]] | la danseuse | les danseurs / les danseuses |
| | [[chanteur\|le chanteur]] | la chanteuse | les chanteurs / les chanteuses |
| **-teur → -trice** | [[directeur\|le directeur]] | la directrice | les directeurs / les directrices |
| | [[facteur\|le facteur]] | la factrice | les facteurs / les factrices |
| | [[acteur\|l'acteur]] | l'actrice | les acteurs / les actrices |
| Masculin seulement 남성만 | [[médecin\|le médecin]] | — | les médecins |

> [!tip] 프린트에서 짚어 둘 것
> - -teur → -trice 칸의 **l'artiste**는 위 칸이 한 번 더 들어간 거예요. artiste는 남녀 모양이 같아요.
> - 🍁 **médecin**은 프린트에 '남성만'으로 나와 있지만 퀘벡에서는 **une médecin**도 써요.

직업을 말할 때는 관사를 빼요.

> **Je suis infirmière.** [🔊](_Audio/je-suis-infirmiere-fad2fd.m4a)
> **Il est médecin.** [🔊](_Audio/il-est-medecin-f1d99e.m4a)

> [!abstract]- 번역
> **Je suis infirmière.** → 나는 간호사예요. (Je suis + 직업, 관사 없이)
> **Il est médecin.** → 그는 의사예요.

## ➕ Un peu plus · 조금 더 (필기)

**더 적어 둔 직업**: [[dactylo|un/une dactylo]] (타자수) · [[épicier|un épicier / une épicière]] · [[gestionnaire|un/une gestionnaire]] (사진 끝이 잘려서 gestionnaire로 읽었어요)

**-eur와 -euse 소리**: -eur는 입을 벌린 [œʁ], -euse는 입을 오므린 [øz] → coiff**eur** [kwafœʁ] · coiff**euse** [kwaføz]

**-teur → -trice**: [[réalisateur|un réalisateur / une réalisatrice]] · [[créateur|un créateur / une créatrice]]
> [!warning] 필기의 ~~réalisateurice~~ · ~~créateurice~~ → **réalisatrice** · **créatrice** (-teur를 통째로 -trice로 바꿔요)

**-ien → -ienne**: [[informaticien|un(e) informaticien(ne)]] · [[mécanicien|un(e) mécanicien(ne)]] · [[technicien|un(e) technicien(ne)]]
> [!warning] 필기 고칠 곳
> - ~~méchanicien~~ → **mécanicien** (h 없음, 영어 mechanic과 달라요)
> - 소리는 -ien [jɛ̃] (비모음) → -ienne [jɛn]. 국적과 같은 규칙이에요 (canadien → canadienne)
