## ❓ Pronom interrogatif « quel » · 무슨, 어느

| | Masculin 남성 | Féminin 여성 |
|---|---|---|
| Singulier 단수 | **quel** | **quelle** |
| Pluriel 복수 | **quels** | **quelles** |

> [!important] 뒤 명사의 성 · 수에 맞춰요. 소리는 넷 다 [kɛl]
> le nom → **quel** · la nationalité → **quelle** · les langues (여성 복수) → **quelles**

> **Quel est ton nom ? — Mon nom est…** [🔊](_Audio/quel-est-ton-nom-mon-nom-est-423ce9.m4a)
> **Quelle est ta nationalité ? — Je suis…** [🔊](_Audio/quelle-est-ta-nationalite-je-suis-2da76e.m4a)
> **Quelle est ta profession ? — Je suis…** [🔊](_Audio/quelle-est-ta-profession-je-suis-766794.m4a)
> **Vous parlez quelles langues ? — Je parle…** [🔊](_Audio/vous-parlez-quelles-langues-je-parle-47a256.m4a)

> [!abstract]- 번역
> **Quel est ton nom ? — Mon nom est…** → 네 이름이 뭐야? — 내 이름은 …야.
> **Quelle est ta nationalité ? — Je suis…** → 국적이 뭐야? — 나는 … 사람이야. (Je suis + 국적)
> **Quelle est ta profession ? — Je suis…** → 직업이 뭐야? — 나는 …야. (Je suis + 직업, 관사 없이)
> **Vous parlez quelles langues ? — Je parle…** → 어떤 언어를 하세요? — 나는 …를 해요.

## 🔤 Les verbes · 동사

| | être (특별) | avoir (특별) | parler (1군) |

| je | suis | j'ai | parle |
| tu | es | as | parles |
| il / elle / on | est | a | parle |
| nous | sommes | avons | parl**ons** |
| vous | êtes | avez | parl**ez** |
| ils / elles | sont | ont | parl**ent** |

> **Je parle français.** [🔊](_Audio/je-parle-francais-c6faec.m4a)
> **Tu parles anglais.** [🔊](_Audio/tu-parles-anglais-e65414.m4a)
> **Il parle espagnol.** [🔊](_Audio/il-parle-espagnol-43d13d.m4a)

> **Tu parles anglais.** → 너는 영어를 해.
> **Il parle espagnol.** → 그는 스페인어를 해요.

## 📋 Enquête · 동료 4명 인터뷰

> **Posez ces questions à au moins 4 collègues.** [🔊](_Audio/posez-ces-questions-a-au-moins-4-collegu-2e89c6.m4a)
> 🔢 Posez ces questions à au moins quatre collègues.

> [!abstract]- 번역
> 적어도 동료 4명에게 이 질문을 하세요.

1. **Quel** est **ton** nom ? — Mon nom est …
2. **Quelle** est **ta** nationalité ? — Je suis + nationalité
3. **Quelle** est **ta** profession ? — Je suis + profession
4. Vous parlez **quelles** langues ? — Je parle …
5. Vous habitez où ? — J'habite **à** + ville / **dans** + arrondissement / **sur** + rue

> **Vous habitez où ?** [🔊](_Audio/vous-habitez-ou-d53551.m4a)
> **J'habite à Montréal.** [🔊](_Audio/j-habite-a-montreal-52d30a.m4a)
> **J'habite dans l'arrondissement Ville-Marie.** [🔊](_Audio/j-habite-dans-l-arrondissement-ville-mar-69a45c.m4a)
> **J'habite sur la rue Sainte-Catherine.** [🔊](_Audio/j-habite-sur-la-rue-sainte-catherine-cef1ba.m4a)

> [!abstract]- 번역
> **Vous habitez où ?** → 어디 살아요?
> **J'habite à Montréal.** → 몬트리올에 살아요. (à + 도시)
> **J'habite dans l'arrondissement Ville-Marie.** → 빌마리 구에 살아요. (dans + 구)
> **J'habite sur la rue Sainte-Catherine.** → 생트카트린 거리에 살아요. (sur + 거리)

### 🗣 Présentations · 동료 소개하기

> **Mon premier collègue s'appelle… / Ma première collègue s'appelle…** [🔊](_Audio/mon-premier-collegue-s-appelle-ma-premie-5a302b.m4a)
> **Il est… Elle est… Il parle… Elle habite…** [🔊](_Audio/il-est-elle-est-il-parle-elle-habite-6b06c4.m4a)
> **Mon deuxième / troisième / quatrième collègue s'appelle…** [🔊](_Audio/mon-deuxieme-troisieme-quatrieme-collegu-689e3a.m4a)

> [!abstract]- 번역
> **Mon premier collègue s'appelle… / Ma première collègue s'appelle…** → 내 첫 번째 동료(남 / 여)의 이름은 …예요.
> **Il est… Elle est… Il parle… Elle habite…** → 그는 …예요 (국적 · 직업). 그는 …를 해요. 그녀는 …에 살아요.
> **Mon deuxième / troisième / quatrième collègue s'appelle…** → 내 두 번째 / 세 번째 / 네 번째 동료 이름은 …예요.

> [!tip] 소개할 때는 **je → il / elle**로 바꿔요: Je suis → Il est · Je parle → Elle parle · J'habite → Il habite
> collègue는 남녀 모양이 같아서 **mon / ma**로 구분해요 (mon collègue · ma collègue)
