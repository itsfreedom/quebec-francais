## 🎭 Jeu de rôles · 역할극

5명 (손님 4 + 주인 1) · 장소: à la porte (문 앞) + sur la terrasse (테라스)

| | 할 일 | 하는 말 |
|---|---|---|
| **Hôte / Hôtesse** 주인 | ① 문에서 손님 맞이하기 | Bonjour (Salut / Allo), *내 이름*, enchanté(e) ! · Ça va ? / Comment ça va ? |
| | ② 다른 손님들에게 소개하기 | Le deuxième / troisième / quatrième invité(e), *손님 이름* |
| **Invité(e)** 손님 | ① 주인에게 인사하기 | Bonjour / Salut / Allo, *내 이름*, enchanté(e) |
| | 주인 질문에 대답하기 | Ça va. / Ça va bien. Merci ! |
| | ② 다른 손님을 소개받으면 | Bonjour / Salut / Allo, enchanté(e) ! |
| **Tout le monde** 모두 | 대화 끝에 잔을 들고 | **Santé !** |
