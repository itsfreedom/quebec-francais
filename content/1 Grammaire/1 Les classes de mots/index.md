> [!abstract] 핵심
> 불어 단어는 **9가지 품사**로 나뉘어요. 문장의 뼈대는 **동사**와 **명사**이고, 나머지는 이 둘을 돕거나 대신하거나 이어 줘요.

| 품사 | 하는 일 |
| --- | --- |
| [[1 Grammaire/1 Les classes de mots/1 Le verbe/index\|동사 (le verbe)]] | 움직임 · 상태를 말해요. 문장의 중심 |
| [[1 Grammaire/1 Les classes de mots/2 Le nom/index\|명사 (le nom)]] | 사람 · 물건 · 생각의 이름. 남성/여성이 있어요 |
| [[1 Grammaire/1 Les classes de mots/3 Le déterminant/index\|한정사 (le déterminant)]] | 명사 앞에서 어떤 것인지 정해요 |
| [[1 Grammaire/1 Les classes de mots/4 Le pronom/index\|대명사 (le pronom)]] | 명사를 대신해요 |
| [[1 Grammaire/1 Les classes de mots/5 L'adjectif/index\|형용사 (l'adjectif)]] | 명사를 꾸며요. 명사의 성 · 수를 따라가요 |
| [[1 Grammaire/1 Les classes de mots/6 L'adverbe/index\|부사 (l'adverbe)]] | 동사 · 형용사를 꾸며요. 모양이 안 바뀌어요 |
| [[1 Grammaire/1 Les classes de mots/7 La préposition/index\|전치사 (la préposition)]] | 명사 앞에서 장소 · 출신 · 방향을 말해요 |
| [[1 Grammaire/1 Les classes de mots/8 La conjonction/index\|접속사 (la conjonction)]] | 단어와 문장을 이어요 |
| [[1 Grammaire/1 Les classes de mots/9 L'interjection/index\|감탄사 (l'interjection)]] | 느낌 · 인사를 혼자 말해요 |

> [!tip] 모양이 바뀌는 품사와 안 바뀌는 품사
> 동사 · 명사 · 한정사 · 대명사 · 형용사는 사람, 성(남/여), 수(단/복)에 따라 모양이 바뀌어요. 그래서 먼저, 더 많이 공부해요.
