# Pronoms sujets (주어 대명사)

← [[00 Grammaire]] · 처음 나온 수업: [[2026-11-18]]

> [!example] 상태: 기초 정리 (수업에서 본격적으로 배우기 전). 수업에서 배우면 내용을 보충해요.

| | 단수 | 복수 |
|---|---|---|
| 1인칭 | **je** 나 | **nous** 우리 |
| 2인칭 | **tu** 너 | **vous** 당신 / 너희 |
| 3인칭 | **il** 그 / **elle** 그녀 / **on** 우리·사람들 | **ils** 그들 / **elles** 그녀들 |

- **tu** = 친한 사이, **vous** = 처음 보는 사람·선생님 (존댓말)
- **je** + 모음 → **j'** (j'ai) → [[02 Élision|Élision]]
- 강조할 때는 **moi**, toi를 써요: Moi, je suis … 
- 말할 때 **on**을 nous 대신 많이 써요
