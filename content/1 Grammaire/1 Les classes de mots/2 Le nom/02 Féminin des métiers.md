> [!important] 남자는 **le / un**, 여자는 **la / une**. 끝 모양을 보고 여성형을 만들어요. 복수는 대부분 **-s** (소리는 같아요).

| 끝 모양 | 남성 | 여성 | 소리 변화 |
|---|---|---|---|
| -er → **-ère** | cuisinier, infirmier | cuisinière, infirmière | [e] → [ɛʁ] (r을 읽어요) |
| -e → **그대로** | dentiste, secrétaire | dentiste, secrétaire | 같아요 (관사만 바뀌어요) |
| + **-e** | avocat, écrivain | avocate, écrivaine | 끝 자음을 읽어요 · 비모음이 사라져요 |
| -eur → **-euse** | coiffeur, chanteur | coiffeuse, chanteuse | [œʁ] → [øz] |
| -teur → **-trice** | directeur, acteur | directrice, actrice | [tœʁ] → [tʁis] |
| -ien → **-ienne** | informaticien, mécanicien | informaticienne, mécanicienne | [jɛ̃] → [jɛn] (국적과 같아요) |

> [!tip] -eur인데 -euse일까 -trice일까?
> 같은 모양의 동사가 있으면 보통 **-euse**: chanter → chanteur → **chanteuse** · vendre → vendeur → **vendeuse**
> 없으면 보통 **-trice**: directeur → **directrice** · acteur → **actrice**

> [!note] 🍁 퀘벡에서는 여성형을 많이 써요
> une **professeure** · une **ingénieure** · une **médecin** (프랑스에서는 médecin을 남성형으로만 쓰기도 해요)

## 직업 말하기
- **Je suis + 직업** (관사 없이): Je suis infirmière. · Il est médecin.
- **C'est + un / une + 직업**: C'est un médecin. · C'est une bonne avocate.
