# Liaison (리에종)

← [[Phonetique]] · 처음 배운 수업: [[2026-11-18]]

[[Lettres muettes|원래 안 읽는 끝 자음]]도 **다음 단어가 모음이나 h로 시작하면** 이어서 읽어요.

- vous‿avez → [vuzave] 부자베 (s → [z])
- vous‿êtes → [vuzɛt] 부제뜨 → [[Verbe etre]]
- les‿amis → [lezami] 레자미 → [[Articles definis]]
- deux‿ans → [døzɑ̃] 되장
- un‿ami → [œ̃nami] 아나미

> [!warning] [[et]] 뒤에서는 절대 이어 읽지 않아요
> et / un ami → [e œ̃nami]
