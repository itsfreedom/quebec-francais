# Articles définis (정관사)

← [[Grammaire]] · 처음 나온 수업: [[2026-11-18]]

> [!example] 상태: 기초 정리 (수업에서 본격적으로 배우기 전). 수업에서 배우면 내용을 보충해요.

| | 단수 | 복수 |
|---|---|---|
| 남성 | **le** lit | **les** lits |
| 여성 | **la** rue | **les** rues |
| 모음 · h 앞 | **l'**ami, **l'**eau | **les** amis |

- le / la → 모음 앞에서 **l'** → [[Elision]]
- les + 모음 → [lez]로 이어 읽어요 → [[Liaison]]
